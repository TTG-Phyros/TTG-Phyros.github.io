Area

AREA (Application for Remote Execution of Actions) is a project developed as part of the Epitech curriculum. It is a web and mobile application that automates tasks by connecting different services together.

Inspired by platforms like IFTTT (If This Then That) and Zapier, AREA lets users create actions that trigger in response to specific events, from both a web browser and a mobile app.

MyHunter

MyHunter is a cops-and-robbers game where the player acts as a police officer tasked with eliminating thieves while avoiding civilians. Gameplay is based on a shooting system that requires speed, accuracy, and timing, with penalties for mistakes.

The game features three types of characters: thieves, who score points when neutralized, and civilians, men or women, who must be avoided at all costs. Hitting a civilian results in a heavy point loss.

RType

R-Type is a side-scrolling shooter where the player pilots a spaceship against waves of enemies. Gameplay relies on dodging, strategic weapon use, and the Force module, which is essential for offense and defense.

We developed a multiplayer version of R-Type, including match creation, lobbies to bring players together, and a lag-compensation system. These features enabled a smooth, synchronized experience even with varied network connections.
